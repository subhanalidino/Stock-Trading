# Task 2 - Stock Trading System

## Task Description

A basic Stock Trading System developed in Java using Object-Oriented Programming concepts. 
The program manages stock details, user accounts, and stock transactions.

## Objectives
* Practice Java OOP concepts.
* Create classes, objects, and constructors.
* Implement methods for different operations.
* Demonstrate relationships between classes.

## Technologies Used
* Java
* Object-Oriented Programming (OOP)

## Features
* Display and update stock information.
* Display user account details.
* Deposit and withdraw money.
* Calculate transaction amount.
* Display transaction details.

## Classes
* **Stock** – Manages stock information.
* **User** – Manages user information and balance.
* **Transaction** – Handles stock transaction details and calculations.

## How to Run
Open `stockTrading.java` in any Java-supported IDE and run the program.
